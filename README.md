# BOYNT-WORK
Research and website work for BOYNT

## Website

- `website/` — the site. Upload **both** `index.html` and the `images/` folder to the host, keeping them side by side.
- `single-file/index.html` — the same page with every photo embedded, for hosts that only take one file. Rebuild it after editing the site with `python3 tools/build-single-file.py`.
